# 🤖 FunPay Auto-Bot 2026

Полностью автоматизированный Python-бот для площадки FunPay. Бот сам генерирует товары с помощью ИИ, загружает их на Google Drive и публикует лоты. Тебе нужно только настроить его один раз и запустить.

---

## 📋 Что тебе понадобится

| Что | Зачем | Где взять |
|---|---|---|
| Компьютер на Windows | Чтобы запускать бота | Твой ПК |
| Python 3.10 или новее | Чтобы бот мог работать | [python.org](https://python.org) |
| Аккаунт FunPay | Чтобы публиковать лоты | [funpay.com](https://funpay.com) |
| Golden Key от FunPay | Пароль для бота | В настройках FunPay |
| Аккаунт Google | Для Google Drive | [accounts.google.com](https://accounts.google.com) |
| Интернет | Для работы бота | Твой провайдер |

## 🚀 Установка (пошагово)

### Шаг 1: Установи Python

1. Скачай Python с [python.org](https://python.org) (версия 3.10 или новее)
2. При установке **ОБЯЗАТЕЛЬНО** поставь галочку **«Add Python to PATH»** внизу окна установки
3. Нажми «Install Now» и дождись окончания
4. Проверь: открой командную строку (Win+R → введи `cmd` → Enter) и напиши:
   ```
   python --version
   ```
   Должно показать что-то вроде `Python 3.12.x`. Если показало — всё ок!

### Шаг 2: Скачай бота

1. Скачай архив с ботом с GitHub (кнопка «Code» → «Download ZIP»)
2. Распакуй архив в любую папку, например на рабочий стол
3. Запомни путь к папке — он тебе понадобится

### Шаг 3: Установи зависимости

1. Открой PowerShell (нажми правой кнопкой на меню Пуск → «Windows PowerShell»)
2. Перейди в папку с ботом:
   ```
   cd C:\Users\ТВОЙ_ПОЛЬЗОВАТЕЛЬ\Desktop\rublyevky-15.6
   ```
   (замени путь на свой, если папка в другом месте)
3. Установи нужные библиотеки:
   ```
   pip install -r requirements.txt
   ```
   Подожди пока всё скачается. Это может занять 1-2 минуты.

### Шаг 4: Создай файл .env

1. В папке с ботом создай файл с названием `.env` (именно так, с точкой в начале)
2. Открой его в блокноте и напиши:
   ```
   GOLDEN_KEY=твой_золотой_ключ_от_funpay
   GOOGLE_DRIVE_FOLDER_ID=айди_папки_на_google_drive
   ```
3. Сохрани файл

**Как найти Golden Key:**
- Зайди на FunPay → Настройки → Золотой ключ → Скопируй его

**Как найти Google Drive Folder ID:**
- Создай папку на Google Drive
- Открой её в браузере
- В адресной строке будет что-то вроде: `https://drive.google.com/drive/folders/1qyFeH_ZTZH_iWpaVdJgCgCW1ls5CQ_gu`
- Часть после `folders/` — это и есть ID (в примере это `1qyFeH_ZTZH_iWpaVdJgCgCW1ls5CQ_gu`)

### Шаг 5: Настрой Google Drive

1. Перейди на [Google Cloud Console](https://console.cloud.google.com/)
2. Создай новый проект
3. Включи Google Drive API:
   - Меню слева → APIs & Services → Library
   - Найди «Google Drive API» → Включи
4. Создай Service Account:
   - Меню слева → APIs & Services → Credentials
   - «Create Credentials» → «Service Account»
   - Заполни имя → «Create and Continue» → «Done»
5. Скачай ключ:
   - Кликни на созданный Service Account
   - Вкладка «Keys» → «Add Key» → «Create new key» → JSON → «Create»
   - Скачается файл — переименуй его в `client_secrets.json` и положи в папку с ботом
6. Поделись папкой Google Drive с Service Account:
   - Открой почту Service Account (вкладка «Details» — там будет email вида `xxx@xxx.iam.gserviceaccount.com`)
   - Скопируй этот email
   - На Google Drive: открой свою папку → «Поделиться» → вставь email → дай права «Редактор»

### Шаг 6: Настрой список игр

1. Открой файл `data/games_list.txt` в блокноте
2. Добавь игры, по одной на строку, в формате:
   ```
   Название игры
   ```
   Например:
   ```
   Cyberpunk 2077
   Hogwarts Legacy
   Valheim
   ```
3. Сохрани файл

## 🌐 Настройка сети (Обязательно для России!)

Если ты в России — FunPay заблокирован РКН и не открывается напрямую. Нужно настроить Запрет + WARP.

### Шаг 1: Установи Запрет

1. Скачай Запрет: https://github.com/Flowseal/zapret-discord-youtube/releases
2. Распакуй в любую папку
3. Открой папку `lists` → файл `list-general.txt` → добавь в конец:
   ```
   funpay.com
   cdn.funpay.com
   api.funpay.com
   ```
4. Сохрани файл

### Шаг 2: Найди рабочую стратегию Запрета

1. Запусти `service.bat` **от имени администратора** (правая кнопка → Запустить от имени администратора)
2. Введи `11` (Run Tests) → Enter
3. Запрет сам найдёт лучшую стратегию для твоего провайдера
4. Запомни номер стратегии (обычно ALT3, ALT11 или SIMPLE FAKE)

### Шаг 3: Запусти Запрет

1. Запусти нужный `.bat` файл **от имени администратора** (например `general (ALT3).bat`)
2. Появится чёрное окно — **не закрывай его**, Запрет работает
3. Если Windows Defender ругается → «Дополнительные сведения» → «Выполнить в любом случае»

### Шаг 4: Установи Cloudflare WARP

1. Скачай WARP: https://1.1.1.1/
2. Нажми кнопку **Windows**
3. Установи программу
4. При выборе режима выбери **«Приватный просмотр»** → нажми «Принять условия и продолжить»
5. **НЕ выбирай** «Cloudflare One Client» — это для бизнеса!

### Шаг 5: Настрой WARP на протокол MASQUE

Это **самый важный шаг** — без него WARP не будет работать из России!

1. Нажми `Win + R` → введи `cmd` → нажми `Ctrl+Shift+Enter` (от имени администратора)
2. Введи по очереди (каждую строку — Enter, ждёшь ответа):
   ```
   warp-cli registration delete
   warp-cli registration new
   warp-cli tunnel protocol set MASQUE
   warp-cli tunnel masque-options set h2-only
   ```
3. Закрой CMD

### Шаг 6: Подключи WARP

1. В системном трее (рядом с часами) найди иконку WARP
2. Включи ползунок «Подключено»
3. Должно написать «Connected» — всё работает! ✅

### Шаг 7: Проверь

1. Открой браузер → зайди на **funpay.com**
2. Если открывается — всё настроено правильно! 🎉
3. Если не открывается — попробуй другую стратегию Запрета (Шаг 2)

## 📁 Что делает бот (подробно)

1. **Берёт первую игру** из списка `games_list.txt`
2. **Ищет категорию** на FunPay (Услуги или Прочее)
3. **Генерирует 15 товаров** с помощью ИИ (3 обязательных + 12 от ИИ)
4. **Создаёт гайд** для каждого товара и загружает на Google Drive
5. **Публикует лот** на FunPay за 1 рубль
6. **Если игра есть в WeMod** — публикует ещё один лот за 60 рублей
7. **Удаляет игру** из списка и переходит к следующей
8. **Повторяет** пока список не кончится

## ❓ Частые проблемы

### «GOLDEN_KEY не найден в .env»
- Убедись что файл `.env` существует в папке с ботом
- Убедись что внутри написано `GOLDEN_KEY=твой_ключ` (без пробелов вокруг =)
- Убедись что файл называется `.env`, а не `.env.txt`

### «SSL: UNEXPECTED_EOF_WHILE_READING»
- Это значит FunPay заблокирован. Настрой Запрет + WARP (см. раздел «Настройка сети»)
- Если WARP уже подключён — попробуй перезапустить его и Запрет

### «FunPay недоступен: ConnectTimeout»
- Проверь что WARP подключён (зелёный ползунок)
- Проверь что Запрет работает (чёрное окно открыто)
- Попробуй зайти на funpay.com в браузере — если не открывается, значит сеть не настроена

### «❌ ОТКАЗ: server_id»
- Бот уже исправлен — обнови до версии 15.6+
- Скачай свежий код с GitHub

### «❌ ОТКАЗ: Много предложений»
- Это нормально — FunPay ограничивает количество лотов в категории
- Бот автоматически перейдёт к следующей игре

### «ИИ отказался писать гайд»
- Иногда ИИ не хочет писать на спорные темы — бот пропустит этот товар
- Это нормально, бот продолжит работу

### «🚫 Cloudflare заблокировал IP»
- Бот автоматически подождёт 15 минут и попробует снова
- Если не помогает — перезапусти WARP (выключи и включи ползунок)
- Если совсем не помогает — подожди 30-60 минут

### WARP не подключается
- Убедись что Запрет запущен и работает
- Открой CMD от администратора и введи:
  ```
  warp-cli registration delete
  warp-cli registration new
  warp-cli tunnel protocol set MASQUE
  warp-cli tunnel masque-options set h2-only
  ```
- Перезапусти WARP

### После перезагрузки ПК WARP не работает
- Снова открой CMD от администратора:
  ```
  warp-cli tunnel protocol set MASQUE
  warp-cli tunnel masque-options set h2-only
  ```
- Перезапусти WARP
- Запрет тоже нужно запустить заново (если не установил как службу)

## 🛡️ Безопасность

- Бот использует **случайные задержки** между действиями (7-15 секунд)
- **Рандомный User-Agent** при каждом запуске — Cloudflare не видит паттерн
- **Авто-пауза** при блокировке Cloudflare — 15 минут ожидания
- **Проверка дубликатов** — бот не публикует лоты дважды
- **Логирование** всех ошибок в `logs/errors.log`
