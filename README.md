# FunPay Auto-Bot 2026

Полностью автоматизированный Python-бот для площадки FunPay. Бот генерирует товары с помощью ИИ, загружает их на Google Drive и публикует лоты.

## Установка

1. Установите Python 3.10+
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Настройте файлы в директории `data/`:
   - `games_list.txt`: Список игр в формате `Название | ID | Ссылка`
   - `wemod_games_list.txt`: Список игр, доступных в WeMod (одно название на строку)
   - `cookies.json`: Ваши куки FunPay (в формате JSON, экспортированные из браузера)
4. Получите `credentials.json` от Google Cloud Console (Service Account) и положите в корень проекта.
5. Настройте `.env` файл.

## Особенности
- **ИИ Генерация**: Использует GPT для создания уникального контента и идей товаров.
- **Google Drive**: Автоматическое создание папок и выдача прав доступа по ссылке.
- **Рандомизация**: Каждое описание лота уникально благодаря случайным эмодзи и цветовым схемам.
- **Автономия**: Бот сам удаляет обработанные игры из списка и ведет подробный лог.

## Структура лотов
- **1 рубль**: Текстовые товары (гайды, советы, инструкции). 15 штук на каждую игру.
- **60 рублей**: Доступ к WeMod мод-меню (если игра есть в списке WeMod). Фиксированная ссылка.

## Безопасность
- Используются случайные задержки между действиями.
- Проверка дубликатов перед публикацией.
- Логирование всех ошибок в `logs/errors.log`.
