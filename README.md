# 🤖 FunPay Auto-Bot 2026

Полностью автоматизированный Python-бот для площадки FunPay. Бот сам генерирует товары с помощью ИИ, загружает их на Google Drive и публикует лоты. Тебе нужно только настроить его один раз и запустить.

> **Версия 19.0.** Бот больше не управляет системой: никакого Запрета, WARP и правок маршрутов. ИИ работает через свой Cloudflare Worker — бесплатно и без ключей на ПК (см. `worker/README.md`). Проверка всего перед запуском: `py main.py --selftest`.

## 🚀 Установка (пошагово)

### Шаг 1: Установи Python

1. Скачай Python с [python.org](https://python.org) (версия 3.10 или новее)
2. При установке **ОБЯЗАТЕЛЬНО** поставь галочку **«Add Python to PATH»** внизу окна установки
3. Нажми «Install Now» и дождись окончания
4. Проверь: открой командную строку (Win+R → введи `cmd` → Enter) и напиши:
   ```
   python --version
   ```
   Должно показать что-то вроде `Python 3.12.x`. Если показало — всё ок!

### Шаг 2: Скачай бота

1. Скачай архив с ботом с GitHub (кнопка «Code» → «Download ZIP»)
2. Распакуй архив в любую папку, например на рабочий стол
3. Запомни путь к папке — он тебе понадобится

### Шаг 3: Установи зависимости

1. Открой PowerShell (нажми правой кнопкой на меню Пуск → «Windows PowerShell»)
2. Перейди в папку с ботом:
   ```
   cd C:\Users\ТВОЙ_ПОЛЬЗОВАТЕЛЬ\Desktop\rublyevky-15.6
   ```
   (замени путь на свой, если папка в другом месте)
3. Установи нужные библиотеки:
   ```
   pip install -r requirements.txt
   ```
   Подожди пока всё скачается. Это может занять 1-2 минуты.

### Шаг 4: Создай файл .env

1. В папке с ботом создай файл с названием `.env` (именно так, с точкой в начале)
   - **Как создать:** открой блокнот → Файл → Сохранить как → в поле «Имя файла» напиши `.env` → в поле «Тип файла» выбери «Все файлы» → Сохрани в папку с ботом
   - ⚠️ Если назвать файл `.env.txt` — бот не найдёт его! Убедись что файл называется именно `.env`
2. Открой файл `.env` в блокноте и напиши:
   ```
   GOLDEN_KEY=твой_золотой_ключ_от_funpay
   GOOGLE_DRIVE_FOLDER_ID=айди_папки_на_google_drive
   ```
3. Сохрани файл

**Как найти Golden Key:**
- Зайди на FunPay → Настройки → Золотой ключ → Скопируй его

**Как найти Google Drive Folder ID:**
- Создай папку на Google Drive
- Открой её в браузере
- В адресной строке будет что-то вроде: `https://drive.google.com/drive/folders/1qyFeH_ZTZH_iWpaVdJgCgCW1ls5CQ_gu`
- Часть после `folders/` — это и есть ID (в примере это `1qyFeH_ZTZH_iWpaVdJgCgCW1ls5CQ_gu`)

### Шаг 5: Настрой Google Drive

1. Перейди на [Google Cloud Console](https://console.cloud.google.com/)
2. Создай новый проект:
   - Вверху слева нажми на название проекта → «New Project» → введи любое имя → «Create»
3. Включи Google Drive API:
   - Меню слева (три полоски) → APIs & Services → Library
   - Введи в поиск «Google Drive API» → нажми на него → «Enable»
4. Создай Service Account:
   - Меню слева → APIs & Services → Credentials
   - Нажми «Create Credentials» вверху → «Service Account»
   - Введи любое имя (например `funpay-bot`) → «Create and Continue» → «Done»
5. Скачай ключ:
   - Нажми на созданный Service Account в списке
   - Перейди на вкладку «Keys» вверху
   - «Add Key» → «Create new key» → выбери «JSON» → «Create»
   - Скачается файл — **переименуй его в `client_secrets.json`** и положи в папку с ботом
   - ⚠️ Файл должен называться именно `client_secrets.json`, а не как-то иначе
6. Поделись папкой Google Drive с Service Account:
   - В том же Service Account перейди на вкладку «Details»
   - Скопируй email (он выглядит так: `funpay-bot@твой-проект.iam.gserviceaccount.com`)
   - Открой Google Drive → правой кнопкой на свою папку → «Поделиться»
   - Вставь этот email → выбери «Редактор» → «Отправить»

> **Примечание:** При первом запуске бота откроется браузер и попросит авторизоваться в Google — разреши доступ. После этого создастся файл `token.json` — его не удаляй, он нужен для работы.

### Шаг 6: Настрой список игр

1. Открой файл `data/games_list.txt` в блокноте
2. Добавь игры, по одной на строку, в формате:
   ```
   Название игры
   ```
   Например:
   ```
   Cyberpunk 2077
   Hogwarts Legacy
   Valheim
   ```
3. Сохрани файл

## ☁️ Настройка ИИ (Cloudflare Worker)

Бот берёт тексты у нейросетей через **свой Cloudflare Worker**. Это бесплатно (10 000 «нейронов» в сутки, карта не нужна), и ключи ИИ хранятся не на твоём ПК, а внутри Worker'а.

Подробная инструкция со скриншотными шагами: **[worker/README.md](worker/README.md)**

Коротко, что нужно сделать один раз:

1. Зарегистрироваться на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up) (почта + пароль).
2. **Workers & Pages → Create → Create Worker → Deploy**, затем вставить код из `worker/worker.js` и нажать **Deploy**.
3. В настройках Worker'а добавить секрет `PROXY_TOKEN` — пароль между ботом и Worker'ом.
4. Добавить привязку **Workers AI** с именем `AI` (даёт бесплатные модели Cloudflare).
5. Вписать в `.env` две строки:
   ```
   AI_WORKER_URL=https://ai-worker.твой-логин.workers.dev
   AI_WORKER_TOKEN=придуманный_пароль
   ```
6. Проверить: `py main.py --selftest`

**Никаких Запретов, WARP и прав администратора больше не нужно.** Если FunPay у тебя открывается напрямую — бот просто работает. Если когда-нибудь перестанет открываться, в `.env` есть необязательная строка `PROXY_URL=http://логин:пароль@адрес:порт` — этого достаточно.

### Хочешь модели посерьёзнее (Gemini / Groq)?

Добавь в настройках Worker'а секрет `GEMINI_API_KEY` (или `GROQ_API_KEY`) и укажи в `.env`:
```
AI_MODEL_PRIORITY=gemini-2.5-flash,@cf/openai/gpt-oss-120b
```
Бот идёт по списку слева направо: не ответила первая модель — берёт следующую.

## 📁 Что делает бот (подробно)

1. **Берёт первую игру** из списка `games_list.txt`
2. **Ищет категорию** на FunPay (Услуги или Прочее)
3. **Генерирует 15 товаров** с помощью ИИ (3 обязательных + 12 от ИИ)
4. **Создаёт гайд** для каждого товара и загружает на Google Drive
5. **Публикует лот** на FunPay за 1 рубль
6. **Если игра есть в WeMod** — публикует ещё один лот за 60 рублей
7. **Удаляет игру** из списка и переходит к следующей
8. **Повторяет** пока список не кончится

## ❓ Частые проблемы

### «GOLDEN_KEY не найден в .env»
- Убедись что файл `.env` существует в папке с ботом
- Убедись что внутри написано `GOLDEN_KEY=твой_ключ` (без пробелов вокруг =)
- Убедись что файл называется `.env`, а не `.env.txt`

### «❌ ОТКАЗ: server_id»
- Бот уже исправлен — обнови до свежей версии
- Скачай свежий код с GitHub

### «❌ ОТКАЗ: Много предложений»
- Это нормально — FunPay ограничивает количество лотов в категории
- Бот автоматически перейдёт к следующей игре

### «ИИ отказался писать гайд»
- Модель не захотела писать на спорную тему — бот попробует следующую модель, а если все откажутся, пропустит этот товар
- Дальше он продолжит работу сам

### «🚫 Cloudflare заблокировал IP»
- Бот подождёт 15 минут и попробует снова
- Если повторяется — проверь, открывается ли funpay.com в браузере; при необходимости укажи прокси в `.env`

### «ИИ не настроен: в .env нет AI_WORKER_URL»

- Worker ещё не поднят. Инструкция: `worker/README.md` (10 минут, бесплатно)
- Как временное решение можно установить библиотеку `g4f` (`pip install g4f`) — бот сможет работать без Worker'а, но менее стабильно

### «Worker отклонил токен»

- Значение `AI_WORKER_TOKEN` в `.env` должно совпадать с секретом `PROXY_TOKEN` внутри Worker'а
- Проверь, что нет лишних пробелов в начале и конце строки

### «429 ai_limit_reached» / «дневной лимит нейронов исчерпан»

- Это нормально: бесплатные 10 000 нейронов на сутки закончились (сброс в 03:00 по Москве)
- Бот сам подождёт и продолжит с того же места
- Хочешь быстрее — подключи Gemini/Groq через тот же Worker или тариф Workers $5/мес

### «FunPay недоступен / ConnectTimeout / SSL обрыв»

- Зайди на funpay.com в браузере. Если открывается — просто перезапусти бота
- Если не открывается — укажи прокси в `.env`: `PROXY_URL=http://логин:пароль@адрес:порт`
- Проверь, какой адрес Worker'а в `AI_WORKER_URL`: если Worker тоже не открывается, дело в провайдере

### Сайт Worker'а (`*.workers.dev`) не открывается в браузере

- Некоторые провайдеры в РФ ограничивают доступ к Cloudflare — попробуй через мобильный интернет
- Если не открывается вообще никак — нужен прокси или VPS за границей (код бота останется тем же)

## 🛡️ Безопасность

- Бот использует **случайные задержки** между действиями (7-15 секунд)
- **Рандомный User-Agent** при каждом запуске — Cloudflare не видит паттерн
- **Авто-пауза** при блокировке Cloudflare — 15 минут ожидания
- **Проверка дубликатов** — бот не публикует лоты дважды
- **Логирование** всех ошибок в `logs/errors.log`
